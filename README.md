# Super-project

**Автор**: [Николай Калашников]
Описание: Приложение для поиска пользователей GitHub с выводом списка результатов и сохранением в избранное.

**Как использовать API**
Приложение использует GitHub Search API.
Базовый URL: https://api.github.com/search/users?q={username}
Данные приходят в формате JSON.

**Инструкция по запуску**
1. Установите библиотеку requests: pip install requests
2. Запустите скрипт: python main.py
3. Введите имя пользователя (например, octocat) и нажмите "Найти"
4. Выберите пользователя из списка, нажмите "В избранное"

Примеры тестов
- Пустой ввод: предупреждение
- Несуществующий юзер: "Пользователи не найдены"
- Дубликаты: повторное добавление невозможно

**Версии Python**: 3.7+
