# Super-project

**Автор**: [Николай Калашников]  
**Описание**: Приложение для быстрого поиска профилей пользователей GitHub и сохранения их в локальный список избранного.

**Как использовать API**
Приложение использует публичное **GitHub REST API**. 
- Базовый URL: `https://api.github.com/users/{username}`
- Для работы не требуется токен (при небольшом количестве запросов), данные приходят в формате JSON.

 **Инструкция по запуску**
1. Установите библиотеку requests: `pip install requests`
2. Запустите скрипт: `python main.py`
3. Введите имя пользователя (например, `octocat`) и нажмите "Найти".
4. Нажмите "В избранное", чтобы сохранить пользователя в файл `favorites.json`.

 **Примеры тестов**
- Пустой ввод: Если оставить поле пустым и нажать "Найти", появится предупреждение.
- Несуществующий юзер: Поиск по запросу "ihuasf74362" выведет сообщение "Пользователь не найден".
- Дубликаты: Приложение не добавляет одного и того же пользователя в избранное дважды.
